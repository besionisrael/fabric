Package Documentation
Implements the ZooKeeper-coordinated baseline (Paper 3, §III.B). This is the "external coordination service" of the ZK + DLT baseline, evaluating global usage constraints (C_global) before transaction submission.

Protocol:

Client calls Reserve(group, agent, maxConcurrent) before endorsing
If admitted: coordinator reserves a slot and returns reservation ID
Client endorses/submits transaction to Fabric
After commit: client calls Confirm(reservationID)
After abort: client calls Cancel(reservationID)
Implementation note: In-memory state with mutex serialization; production would use ZooKeeper znodes and distributed ephemeral locks.

Chaincode Documentation
DirectedTraceability implements the directed traceability protocol (M_D), enforcing local constraints at endorsement time. Global concurrent constraint (C_global) is evaluated by the constraint-aware orderer or ZooKeeper coordinator (Paper 3's three architectures).

Resource Model: Use-case agnostic traceable entities with domain semantics in Type field (e.g., "specimen", "dataset", "funds") and governance rules in Conditions field traveling with resource through transfers. Trace is append-only, valid by construction (Paper 2, Def. 9).
